# Telemetry and Topology JSON Schemas

This document defines the JSON data contracts and schemas utilized throughout the **SDN Network Diagnostic and Path Analysis Suite**.

---

## 1. Active UDP Probe Protocol Packets

### 1.1 Client Probe Packet (Transmitted to UDP Probe Server)
```json
{
  "magic": "SDN_PROBE",
  "version": "1.0",
  "probe_id": "p-a1b2c3d4",
  "seq": 1,
  "send_time": 1729350000.123456,
  "payload_pad": "XXXXXXXXXXXXXXXXXXXXXXXX..."
}
```

| Field | Type | Description |
|---|---|---|
| `magic` | `string` | Magic identifier string (`SDN_PROBE`) to filter and reject stray non-diagnostic packets. |
| `version` | `string` | Diagnostic probe wire protocol version (`1.0`). |
| `probe_id` | `string` | Unique UUID hex string identifying the individual probe packet. |
| `seq` | `integer` | Monotonically increasing 1-indexed sequence number. |
| `send_time` | `float` | High-precision client Unix epoch timestamp in seconds at socket transmission. |
| `payload_pad` | `string` | Padding string adjusting probe frame to requested `--size` (bytes). |

---

### 1.2 Server Echo Reply Packet (Returned to Client)
```json
{
  "magic": "SDN_PROBE",
  "version": "1.0",
  "probe_id": "p-a1b2c3d4",
  "seq": 1,
  "client_send_time": 1729350000.123456,
  "server_recv_time": 1729350000.124500,
  "server_send_time": 1729350000.124600,
  "status": "OK"
}
```

| Field | Type | Description |
|---|---|---|
| `magic` | `string` | Protocol magic header confirming valid echo. |
| `version` | `string` | Protocol version (`1.0`). |
| `probe_id` | `string` | Mirrored unique probe UUID. |
| `seq` | `integer` | Mirrored sequence number. |
| `client_send_time` | `float` | Preserved client departure timestamp. |
| `server_recv_time` | `float` | Server arrival timestamp recorded immediately upon socket recv. |
| `server_send_time` | `float` | Server departure timestamp recorded immediately before socket sendto. |
| `status` | `string` | Status acknowledgement string (`OK`). |

Generated by `sdn_topology.py` and `sdnscope topo`. Represents discovered OpenFlow network elements.
